# Task 12 - TimeFlow Wallpaper Sync

## About

TimeFlow is a Python program that reads a text file and displays its contents directly on the desktop wallpaper.

It is useful for keeping a daily plan, notes, tasks, or schedule visible on the desktop. The wallpaper also contains a clock that shows the current time with seconds.

The program keeps running and checks the notes file and the current time every second. If the notes are changed or the time changes, a new wallpaper is generated and applied automatically.

---

## Files

### `timeflow.py`

The main Python program. It handles:

* Reading `notes.txt`
* Creating the wallpaper
* Drawing the notes on the image
* Displaying the current time
* Setting the generated image as the desktop wallpaper
* Continuously checking for changes

### `notes.txt`

The input text file.

Example:

```text
TODAY'S PLAN

09:00 - Python practice
11:00 - College work
14:00 - Complete AMFOSS task
18:00 - GitHub work
21:00 - Review today's work
```

Any text written in this file can be displayed on the wallpaper.

### `requirements.txt`

Contains the external Python dependency required by the project.

### `timeflow_wallpaper.png`

The wallpaper generated by the program.

## Usage

Make sure `notes.txt` is present in the same directory as `timeflow.py`.

Run the program with:

```bash
python3 timeflow.py
```

No command-line arguments are required.

The program automatically uses:

```text
notes.txt
```

When it starts, it displays:

```text
Watching: /path/to/notes.txt
Press Ctrl+C to stop.
```

The generated wallpaper is saved as:

```text
timeflow_wallpaper.png
```

Press `Ctrl+C` to stop the program.

## How It Works

The program follows this basic process:

```text
             notes.txt
                 ↓
          Read the contents
                 ↓
       Create wallpaper with Pillow
                 ↓
        Add notes + current time
                 ↓
       Save the wallpaper image
                 ↓
        Set it as desktop wallpaper
                 ↓
            Wait 1 second
                 ↓
       Check notes and current time
                 ↓
              Repeat
```

### 1. Reading the notes

The program reads `notes.txt` using UTF-8 encoding.

If the file does not exist, the program displays a message asking the user to create it instead of stopping with an error.

### 2. Creating the wallpaper

Pillow is used to create a 1920×1080 image.

The generated wallpaper contains:

* `TIMEFLOW` title
* Notes from `notes.txt`
* Current time in `HH:MM:SS` format

The notes are drawn line by line on the image.

### 3. Updating the clock

The current time is obtained using Python's `datetime` module.

The program checks the time every second. Since the seconds change, the wallpaper is regenerated so that the displayed clock stays current.

For example:

```text
14:52:01
14:52:02
14:52:03
```

### 4. Detecting note changes

The program keeps the previous contents of the notes file.

When the contents become different from the previous version, the wallpaper is regenerated with the new text.

This means `notes.txt` can be edited while TimeFlow is running without restarting the program.

### 5. Setting the wallpaper

On Linux, the program uses GNOME's `gsettings` command to set the generated image as the desktop background.

Basic Windows support is also included using the Windows system API.

## Challenges

One of the main challenges was connecting the Python program with the desktop environment.

Generating an image with Pillow is different from actually making that image the desktop wallpaper. On Linux, this required using the GNOME `gsettings` command, while Windows uses a different system API.

Another challenge was keeping the clock updated while also detecting changes in the notes file. The program solves this by checking both the file contents and the current time once every second.

This task helped me understand how Python can interact with files, images, and operating-system features instead of only performing terminal-based operations.
